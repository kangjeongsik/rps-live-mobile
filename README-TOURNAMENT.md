# RPS LIVE v0.7.0 — 혼합형 토너먼트

기존 v0.6.0 일반 LIVE 모드를 유지하면서 토너먼트 모드를 추가했습니다.

## 주소
- 기존 LIVE: `/`
- 기존 LIVE 관리자: `/admin`
- 토너먼트 참가/관전: `/tournament`
- 토너먼트 관리자: `/tournament/admin`

## 설치/배포
기존 GitHub 저장소에 이 ZIP의 파일을 덮어쓰기한 후 Render에서 재배포합니다. `ADMIN_PASSWORD`(12자 이상)를 Render Environment에 설정하세요. `npm start`로 실행됩니다. 외부 공개 전에 관리자 인증을 확인하세요.

## 대회 운영
1. 토너먼트 관리자에서 익명 또는 인증코드 모드를 선택하고 `새 대회 초기화` 클릭
2. 인증코드 모드라면 코드를 발급해 참가자별로 전달 (코드는 1회만 사용)
3. 참가 링크 공유 후 최소 2명 등록
4. `대진 추첨 · 대회 시작` 클릭
5. `경기 시작 / 다음 경기` 클릭해 라운드 진행
6. 예선~8강은 동시에 진행, 4강·결승은 한 경기씩 진행
7. 무승부는 재경기, 한 명만 선택하면 그 사람이 승리, 양측 미선택은 재경기
8. 탈락자도 채팅과 대진표 관전 가능

## 알려진 제한
- 서버 재시작·슬립 시 참가자·인증코드·대진표·채팅 기록이 사라집니다. 실전 상품 대회 전에 DB 영속화 필요.
- 100~200명 동시 접속 부하 테스트 전이며, 서버는 단일 인스턴스 전용입니다.
- 참가 토큰은 브라우저 localStorage에 저장됩니다. 브라우저를 변경하거나 저장소를 지우면 기존 참가자 복구가 어렵습니다.
- 관리자 인증은 HTTPS와 강력한 비밀번호가 필수입니다.
- 대진표는 현재 라운드 중심이며 전체 과거 라운드 기록과 개별 경기 선택 관전, 상품 청구는 미구현입니다.
- 10초 선택 잠금은 기존 LIVE 모드와 동일하게 유지했습니다. 토너먼트의 경기 시간은 15~120초로 설정할 수 있습니다.
